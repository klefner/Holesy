# Harvest County Runtime Assets

Browser-ready assets for the Harvest County city recipe introduced in `Master 16.182`.

Sources:

- Quaternius Farm Buildings: https://quaternius.com/packs/farmbuildings.html
- Quaternius Farm Animals: https://quaternius.com/packs/farmanimal.html
- Quaternius Ultimate Crops: https://quaternius.com/packs/ultimatecrops.html
- Quaternius Simple Nature: https://quaternius.com/packs/simplenature.html

License: CC0 1.0 Universal / Public Domain Dedication.

Runtime rules:

- Source OBJ/MTL files remain in the governed intake area and are not shipped.
- Runtime presentation assets are binary glTF 2.0 under `runtime/`.
- Six building models also have immutable `v1.0.0` authored-surface destruction assets under `converted/`.
- Buildings use the shared imported-city breach, physical-fit, jam, settle, cleanup, and five-voice audio contracts.
- Windmill blades and the water-tower tank are explicit asset-level conversion exceptions retained inside their structural grids.
