# Medieval Village Source Pack

Source asset intake for Holesy theme/world work. `Master 16.172` converts the ten complete OBJ buildings into optimized GLB runtime assets under `assets/environments/medieval-village/runtime/`; runtime code does not load these raw source files.

Source:

- Google Drive: https://drive.google.com/drive/folders/18T92VcNldHG0ugWo1u0hSJGDLua-n7o5
- Creator/license text identifies the pack as LowPoly Models by @Quaternius.
- License: CC0 1.0 Universal / Public Domain Dedication.

Local coverage captured on 2026-06-13:

- `Buildings/OBJ/`: complete OBJ/MTL building set: Bell_Tower, Blacksmith, House_1, House_2, House_3, House_4, Inn, Mill, Sawmill, Stable.
- `Buildings/FBX/`: complete FBX building set from the same building list.
- `Buildings/Blends/`: complete Blender building set from the same building list.
- `Props/Blends/`: partial duplicate prop source capture before Google Drive blocked one file during folder download.

Remaining source folders are documented in the governed intake note and should be refetched or selectively converted during the future medieval-theme implementation pass.
