## Holesy Project Index

This index is the fast navigation file for the Holesy local project directory.

### Where To Look

- Governance and operating rules:
  `00_ADMIN/Policies_and_Procedures/`

- Requirements and product decisions:
  `00_ADMIN/Requirements/`

- Reviews, assessments, and Word documents:
  `00_ADMIN/Reviews_and_Reports/`

- Active working source basis:
  `10_SOURCE/Current/`

- Promoted milestone versions:
  `10_SOURCE/Masters/`

- Preserved imported/comparison baselines:
  `10_SOURCE/Baselines/`

- Test builds likely to become a master:
  `20_TESTS/Candidate_Builds/`

- Experimental or narrow-scope test builds:
  `20_TESTS/Exploratory_Builds/`

- Historical retired files:
  `30_ARCHIVE/`

### Current Conventions

- Only one file should be the active source basis at a time.
- Do not place governance documents beside source HTML files.
- Do not overwrite old masters.
- New test files should always indicate purpose in the filename.
