## License controls

### Quaternius: CC0 1.0

Every matched Quaternius pack page states CC0 and permits personal and commercial project use. CC0 permits copying, modification, distribution, and commercial use without required attribution. It carries no warranty and does not clear unrelated trademark, privacy, or publicity rights.

- License: https://creativecommons.org/publicdomain/zero/1.0/
- Creator/catalog: https://quaternius.com/
- Required credit: none
- Recommended voluntary credit: `Selected 3D assets by Quaternius (CC0).`
- Production state: cleared, subject to normal technical and content review

### Sketchfab: CC Attribution 4.0

CC BY 4.0 permits commercial use and adaptation, but distributed work must give appropriate creator credit, link the license, link the source, and indicate that changes were made.

- License: https://creativecommons.org/licenses/by/4.0/
- Required credit: yes; use the exact entries in the attribution section below
- Production state: cleared only when the shipped credits satisfy those conditions

### Sketchfab: Free Standard

Sketchfab's Free Standard listing points to the Fab Standard License. It permits commercial/private use, modification, and distribution as part of a project, but not resale or redistribution of the asset on a standalone basis.

- License landing page: https://sketchfab.com/licenses
- Current Fab EULA: https://www.fab.com/eula
- Required credit: not required by the Standard License
- Packaging control: incorporate, optimize, bake, or otherwise ship only as part of Holesy; never publish the original ZIP or offer the raw model as a reusable asset pack
- Production state: conditional on the model-specific controls below

## Production intake procedure

1. Match the proposed source ZIP to this ledger by SHA-256.
2. Confirm its model-specific decision is `cleared`, not `hold`.
3. Preserve the official source URL, creator, model UID where applicable, and license in the town's intake manifest.
4. Apply NoAI restrictions before any processing workflow is selected.
5. Convert and optimize into a town-owned runtime derivative; never copy source ZIPs into the release package.
6. Add the required CC BY credit before the first test build that contains the asset.
7. Record material edits such as retopology, texture replacement, mesh separation, animation changes, and destructive-state derivatives.
8. Recheck the official listing and license immediately before first production promotion.
9. Treat replacement files or hash changes as a new intake requiring a new register entry.
